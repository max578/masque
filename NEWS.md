# masque 0.2.0.9000 (in development)

* Initial scaffold for the v0.2 rewrite of the package formerly known as
  `synthPR`. Scope pivoted from folder-scanning multi-file synthesiser
  (v0.1.0, archived) to a single-file tabular dataset masker with a
  round-trippable recipe.
* Two-mode design (`local` vs `collaborate`) and strict 5-role taxonomy
  (`design`, `treatment`, `outcome`, `covariate`, `ignore`) locked.
* CODEX-consolidated plan at `plan/masque_v0.2_plan.md` (workspace).
* No public API yet. See `plan/masque_v0.2_plan.md` §11 for the build order.
