# Code of Conduct

The `masque` project has adopted the Contributor Covenant, version 2.1.

By participating in this project (issues, pull requests, discussions, or any
other form of contribution), you agree to abide by its terms. The full text
of the Covenant is published at:

<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>

## Reporting

Concerns about contributor conduct can be sent to the maintainer at
`max.moldovan@gmail.com`. All reports will be reviewed and acted on
promptly and confidentially. The reporter's identity will not be shared
without their consent.

## Scope

This policy applies to all project spaces — the GitHub repository,
issue tracker, pull request reviews, release notes, and any
communication carried out under the `masque` name.
